以下是您在 Orbid 中会看到的词语。

| 词语 | 含义 |
| --- | --- |
| 案件 | 一项法律工作，包含它的案情、文件和消息。 |
| 填写 | 最初的几个步骤：客户描述案件并上传身份证明文件。 |
| 委托 | 客户与律所之间的约定：审核、接受、报价和付款。 |
| 委托审核 | 律所的列表，列出等待决定是否接受的新案件。 |
| 报价 | 律所给出的固定价格，含事项、币种和截止日期。 |
| KYC | “了解您的客户”，即律师在开始办案前进行的身份核验。 |
| 您编辑的版本 | 您自己的文件副本，您的修改都在其中，原件保持不变。 |
| 案件工作台 | 律师处理已付款案件的工作区，标签页有文件、对话、助理、审核、KYC、事实、补件和交付。 |
| 交付 | 律师选择**交付**并确认，让客户收到最终文件的步骤。 |
| 文件库 | 律所存放文件和条款的地方，可以检索。页面标题为“合同知识库”。 |
| 小欧（XiaoOu） | Orbid 为客户提供的 AI 助手，最终仍由律师决定。 |
| 提交并锁定 | 客户提交案件时的最后一个按钮。点击后，答案就会锁定。 |
