律师在开始办案前，必须先确认您的身份。您在“核验”步骤上传身份证明文件，格式为 PDF、JPEG、PNG、WebP 或 HEIC，每个文件不超过 25 MB。

## 开始之前

- 在设备上准备好您本人或贵公司的身份证明文件。
- 预留几分钟时间。您还需要签署一份简短的声明。

## 可以上传什么？

| 项目 | 限制 |
| --- | --- |
| 文件类型 | PDF、JPEG、PNG、WebP、HEIC |
| 单个文件大小 | 25 MB |
| 每个核验项目的文件数 | 10 个 |
| 一个案件的文件总大小 | 300 MB |

空文件和设置了密码的 PDF 不能上传。仅修改文件名并不能改变文件类型。

## 如何上传？

<Steps>
  <Step title="进入“核验”步骤">
    Orbid 会显示一份清单。每个标有**必填**的项目都至少需要一个文件。
  </Step>
  <Step title="为每个项目上传文件">
    选择项目旁边的**上传文件**。如需更换文件，请先选择**移除**，再上传新的文件。
  </Step>

  <Step title="签名">
    阅读授权说明，并输入签署人的姓名。
  </Step>
  <Step title="提交">
    选择**提交并锁定**。如果有必填项目没有文件，Orbid 会告诉您是哪一项。

## 律所为什么需要这些文件？

律师在接办案件前，必须先了解客户是谁。有些案件需要更全面的核验，可能包括公司的所有者。Orbid 会显示适用哪种核验，具体需要什么由律师决定。

## 我同意了什么？

您确认所提交的文件真实有效，并同意律所处理您的个人信息。这可能包括依据中国的个人信息保护法（PIPL）向德国传输，或依据欧盟的 GDPR 处理。如果您不同意，请在上传前先与律所沟通。

## 上传之后会怎样？

律师会逐项人工查看，并标记为通过。每个必填项目都通过后，律所才能向您发送报价。如果律师需要更多材料，您会在工作区看到相应的请求。详见[跟踪案件进度](/zh-CN/clients/track-your-matter)。

<Info>
Orbid 的 AI 可能会提示问题，例如文件已过期或不清晰。最终始终由律师决定。
</Info>

## 遇到问题怎么办

| 您看到的提示 | 处理方法 |
| --- | --- |
| “文件过大（每个文件最大 25 MB）” | 压缩文件，或把页数分到多个文件中上传。 |
| “本案件的文件总大小超过 300 MB” | 移除不需要的文件。 |
| “不支持的文件类型” | 将文件另存为 PDF、JPG、PNG、WebP 或 HEIC。 |
| “PDF 已加密” | 去掉密码后重新上传。 |
| “该文件似乎已过期” | 请上传有效的文件。 |
| “文件难以辨认” | 重新拍照或扫描。 |
| “部分必填项目还没有文件” | 为每个标有**必填**的项目添加文件。 |
