律所接受您的委托后，会发给您一个固定价格。核对无误后，选择**确认并付款**。付款完成后，律师开始办案。

## 开始之前

- 等到案件显示有报价，您会看到“律师已设定固定价格，确认并付款后即开始办理”。
- 如果贵公司限制了谁可以付款，请确认您的账号有这个权限，否则请联系公司管理员。审批人或财务成员可以付款。

## 需要核对什么？

报价卡会显示详细内容。

| 项目 | 核对要点 |
| --- | --- |
| 固定价格 | 您要支付的总额 |
| 币种 | 欧元（EUR）、美元（USD）或人民币（CNY） |
| 有效期至 | 最后一天。卡片上也会写还剩几天，例如“剩 5 天”。通常为 14 天，律所可设置 1 至 60 天。 |
| 版本 | 新的报价会替代旧的报价。 |

如果日期已过，卡片会显示“已过期”。请看下方“遇到问题怎么办”。

## 状态标签是什么意思？

您的案件会显示下列其中一个标签。

| 标签 | 含义 |
| --- | --- |
| 尚未开始 | 您还没有提交案件。 |
| 等待审核 | 已提交，我们正在安排律师审核。 |
| 已接受 | 律所已接受您的案件，接下来会发来报价。 |
| 未接受 | 律所拒绝了。您可以修改后重新提交。 |
| 已报价 | 律师已设定固定价格，确认并付款后即开始办理。 |
| 已付款 | 已付款，律师已开始办理。 |
| 退回修改 | 律所把案件退回给您。请修改后再提交。 |
| 已取消 | 案件已取消，不会再有后续操作。 |

## 如何付款？

<Steps>
  <Step title="打开案件">
    选择有报价的案件。
  </Step>
  <Step title="核对报价">
    确认这是最新的报价，且尚未过期。
  </Step>
  <Step title="付款">
    选择**确认并付款**，并按所选付款方式的提示操作。
  </Step>
</Steps>

价格是固定的，您不能在 Orbid 中还价或拒绝。如需调整条件，请联系律所，律所可以重新发送报价。

## 遇到问题怎么办

| 您看到的提示 | 处理方法 |
| --- | --- |
| “该报价已过期，律师会发新的报价给您” | 请等待新的报价，或询问律所。 |
| “报价刚刚更新” | 阅读新的报价后再试一次。 |
| “暂不支持在线付款” | 请联系律所，商定付款方式。 |
| 付款失败 | 先查看报价和付款状态，再重试。如不确定，请先询问律所，避免重复付款。 |
| 已付款但案件没有变化 | 请不要再次付款，直接联系律所。 |
| “您的角色无权执行此操作” | 请联系公司管理员代为付款，或调整您的角色。 |
