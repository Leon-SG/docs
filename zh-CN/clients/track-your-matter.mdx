您的工作区会显示每个案件、办理进度、您的消息，以及律所需要您提供的材料。打开案件，即可看到您的下一步。

## 如何看懂进度条？

| 阶段 | 含义 |
| --- | --- |
| 填写 | 您还在描述案件。 |
| KYC | 您正在上传身份证明文件。 |
| 律师审核 | 律师正在阅读您的案件。 |
| 报价 | 律所已接受，正在发送或已发送价格。 |
| 付款 | 有一份报价等待您确认并付款。 |
| 办理中 | 您已付款，律师正在办案。 |
| 已交付 | 您的文件已准备好。 |

首页会把案件分成三组：**待处理事项**、**办理中**和**已交付**。需要您处理的案件会排在最前面。

每个案件旁还有一个小标签，说明目前的情况。

| 标签 | 含义 |
| --- | --- |
| 填写中 | 您还在撰写答案。 |
| 待确认范围 | 请检查并确认工作内容的范围。 |
| 等您处理 | 有一个步骤在等您。 |
| 等待律师 | 律所正在安排律师，您暂时无需操作。 |
| 律师审核中 | 律师正在阅读您的案件。 |
| 待确认交付 | 文件已送达，请确认您已收到。 |
| 已交付 | 案件已完成。 |

## 如何给律所留言？

<Steps>
  <Step title="打开案件">
    在列表中选择该案件。
  </Step>
  <Step title="选择收件人">
    在“发给”中，选择小欧（XiaoOu，Orbid 的 AI 助手）或您的律师。发送消息并不代表律所已经接受您的委托。
  </Step>
  <Step title="输入并发送">
    输入您的消息并发送。
  </Step>
</Steps>

<Note>
Orbid 的 AI 只是辅助工具。如有任何不确定的地方，请询问您的律师。
</Note>

## 律所要求补充材料怎么办？

律师可以要求您重新上传部分身份证明文件。这些项目会回到“待上传”状态，请为它们上传新文件。旧文件仍会保留记录，但不再算作已通过。

## 遇到问题怎么办

| 您看到的提示 | 处理方法 |
| --- | --- |
| 看不到某个案件 | 请用该案件所属公司的账号登录。贵公司可能把案件限定给了特定人员，请咨询管理员。 |
| 案件显示“等待律师” | 请耐心等待，律所正在安排律师，您暂时无需操作。 |
| 案件被拒绝 | 请查看[重新提交被拒绝的委托](/zh-CN/clients/resubmit-a-declined-matter)。 |
