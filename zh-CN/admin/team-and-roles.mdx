管理员一次最多可以邀请 50 人。请选择角色、发送邀请，并查看结果。

## 开始之前

- 您必须是管理员。
- 准备好邮箱地址，每行一个，或用逗号隔开。

<Steps>
  <Step title="打开成员页面">
    在设置中打开**团队与成员**（律所）或**成员**（客户公司）。
  </Step>
  <Step title="添加邮箱地址">
    在**批量邀请**下，输入最多 50 个邮箱地址。在“身份”旁选择**成员**或**管理员**。
  </Step>
  {/* screenshot: settings-team-invite | “团队与成员”页面：“批量邀请”框中有三个邮箱地址，旁边是“发送邀请”按钮；演示律所“Muster Rechtsanwälte” | role=admin | url=/orbid/settings/team */}
  <Step title="发送并查看结果">
    选择**发送邀请**。Orbid 会显示已发送和未发送的数量。发送失败的地址会留在输入框中，方便您修改。
  </Step>
</Steps>

| 限制 | 数值 |
| --- | --- |
| 每次邀请的邮箱数量 | 50 |

## 有哪些角色？

管理员、合伙人、律师、律师助理、财务、审批人、需求人和查看者。管理员身份通过“成员”或“管理员”开关来设置。您能选择哪些角色，取决于您的账号。邀请已发出，并不表示对方已经加入。

## 遇到问题怎么办

| 您看到的提示 | 处理方法 |
| --- | --- |
| “邮箱地址无效” | 修改该地址。 |
| “已是成员”或“已邀请” | 无需处理。 |
| “席位已满” | 请联系您的 Orbid 对接人增加席位。 |
| “发送失败”或“请稍后再试” | 几分钟后重试。 |
| “一次最多 50 个” | 把剩下的分第二批发送。 |
| “仅管理员可查看” | 请联系管理员。 |
