设置路由提供组织、账户、访问和用量配置入口。路由存在不代表每个账户都能编辑每项设置，也不代表所有连接器均已激活。[S19]

## 查找设置

使用当前工作区的设置入口。律师工作区在共享域名的路由映射使用 `/orbid/settings` 和以下分区标识；专用域名可能使用不同前缀：

| 分区 | 路由后缀 |
| --- | --- |
| 律师事务所/公司资料 | `firm` |
| 连接器 | `connectors` |
| 团队 | `team` |
| 智能体策略 | `agent-policy` |
| 订阅/计费 | `billing` |
| 账户 | `account` |
| 智能体偏好 | `agent` |
| 语言 | `language` |
| 用量 | `usage` |
| 案件访问 | `matter-access` |
| 通知 | `notifications` |
| 审计 | `audit` |

打开相关分区，查看您的角色可用的选项，执行允许的变更，并验证已保存。不要假定可通过直接 URL 使用隐藏控件。客户专属设置有 `/orbid/client/settings` 下的路由，但本次检查的页面在客户设置功能关闭时会返回找不到页面。可用性与可编辑项目取决于设置和权限，也不代表可以管理律所。[S25]

客户设置的路由映射包含以下分区：[S25]

| 分区 | 路由后缀 |
| --- | --- |
| 个人资料 | `profile` |
| 偏好设置 | `preferences` |
| 通知 | `notifications` |
| 安全 | `security` |
| 公司 | `company` |
| 成员 | `members` |
| 案件访问权限 | `matter-access` |
| 计费 | `billing` |
| 审计 | `audit` |

## 团队与邀请

管理员可使用批量邀请功能时，可输入最多 **50** 个地址、选择页面提供的成员或管理员角色，并逐一检查结果。本次检查的流程逐项处理邀请，因此同一次操作可能部分成功；地址无效、席位限制或身份服务不可用都可能导致失败。表单会保留失败项目供修正。邀请已发出不代表对方已加入。[S45]

本次检查的细分成员角色面板在功能开关关闭时会隐藏。面板可用时，只有管理员能更改该组织提供的非管理员角色；此面板不能更改管理员的组织角色。请与管理员确认预期权限及保存结果，不要仅从角色名称推断权限。[S47]

在本次检查的组织成员管理路径中，如果该请求读取的成员清单显示对象是最后一位管理员，系统会拒绝移除或降级。这项检查与身份服务更新是分开的步骤，不能依赖它协调并行变更；请逐一更改管理员并确认结果。如果更改角色或移除成员时报错，重试前请重新加载成员清单并确认结果：这些操作包含多个身份服务步骤，可能在途中失败。如果状态不明确，请联系管理员。[S51] 待确认事项请见 [Q17](/zh-CN/product/open-questions)。

## 连接器

在本次检查的律所连接器设置中，获授权的编辑者可选择启用区域与默认来源。保存偏好不代表连接器已配置完成或可连接。如果没有有效的默认来源且律所来源区域已启用，解析程序会回退到 `knowledge` 默认值；因此取消最后一个默认项目不一定会留下空选择。请确认保存结果与实际来源状态，不要将复选框视为访问控制保证。[S49]

## 通知偏好

如果通知设置区段可用，请选择页面列出的事件及电子邮件或应用内渠道，保存后确认结果。偏好按用户存储，律所与客户端的设置彼此分开。本次检查的代码将未指定的选项默认为启用。受检查的邮件发送流程只对已映射事件应用偏好；其他里程碑邮件仍可能发出，且读取偏好失败时会允许发送。保存偏好并不保证每条通知一定送达或一定被停用。[S26]

## 访问与归属

### 审计记录

本次检查的审计页面不是完整活动记录：审计写入采用尽力处理、拒绝访问事件采用抽样记录，且案件事件记录读取失败时，结果可能只剩组织事件。CSV 导出最多 **5000** 行。可用时请结合筛选与分页，并向负责系统或管理员核对重要事件；缺少记录不能证明操作未发生。[S50]

### 客户公司身份

在本次检查的客户公司设置中，管理员更改法定名称、登记号码或管辖地时，服务器会将变更字段标记为需要 KYC 复核。保存公司资料不代表复核已完成。更改法定名称时也会尝试同步显示名称，但同步可能失败；请确认显示结果，如果仍不一致，请联系管理员或律所。[S44]

### 案件访问权限

在本次检查的案件访问设置中，客户组织管理员可选择 `all` 或 `members` 可见性。额外的成员限制只有在服务器强制模式启用时才会阻止访问；关闭与观察模式不会强制执行。依赖此设置前，请确认部署模式。[S25, S43]

律所设置表单可让管理员保存默认案件成员，但界面说明指出，自动加入新案件属于后续版本。因此，保存默认值不能证明任何人已加入特定案件；请检查该案件的实际成员与访问权限。[S43]

客户组织身份、律师事务所工作区分配、案件可见性和具体操作关卡是不同问题。委托审核和文档工作可能要求不同状态。导航入口不是授权规则。请管理员解决不匹配，不要更改无关组织数据来获取访问。

完整角色/权限矩阵、邀请生命周期、连接器前提、策略效果、审计覆盖和允许的管理变更仍属于 [Q15](/zh-CN/product/open-questions)。

## 计费与下载

本次检查的客户计费页面最多读取公司 **500** 条案件记录。页面显示的付款金额与币种取自该案件最后找到的发票（如有），而非直接取自付款服务商交易；因此付款清单或金额可能不完整，或与实际扣款不同。列出的卡号末四位是曾使用的方式，不代表卡片保管库。请与约定报价及服务商记录核对；如有差异，请联系律所。[S48] 对账待确认事项请见 [Q16](/zh-CN/product/open-questions)。

产品方案信息请见 [orbid.dev/pricing](https://orbid.dev/pricing)。本手册不从源码常量推断价格或额度。客户委托付款依据各自报价；确认前请核对操作与金额。

受支持的公开 API、订阅权益、区域托管、数据保留和服务保证需要明确产品文档。参阅[通用规则](/zh-CN/product/rules)和[待确认事项](/zh-CN/product/open-questions)。
