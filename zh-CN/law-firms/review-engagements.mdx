打开**委托审核**，即可看到等待您决定的新委托。请检查每个委托及其身份证明文件，然后选择接受或拒绝。

## 开始之前

- 您需要在本所拥有律师账号。

<Steps>
  <Step title="打开案件">
    在列表中选择一个案件，阅读摘要和身份核验清单。
  </Step>
  <Step title="逐项核对身份证明">
    打开每个必填项目并查看文件。选择**通过**或**未通过**，再选择**保存核验结果**。未通过时必须填写原因，客户看不到这个原因。如需更多材料，请选择**要求补件**。
  </Step>
  {/* screenshot: counsel-kyc-check | 委托审核中的身份核验清单：一项设为“通过”，一项设为“未通过”并已填写原因，旁边有“保存核验结果”按钮；演示客户“Demo GmbH” | role=lawyer | url=/orbid/counsel/engagements */}
  <Step title="接受或拒绝">
    选择**接受本案**，继续出具报价。如需拒绝，请选择**拒绝本案**，写明给客户的理由，再选择**确认拒绝**。
  </Step>
</Steps>

## 如何拒绝委托？

请写明至少 10 个字符的理由，客户可以看到。您还可以另写一条内部备注，只有律师能看到。被拒绝的客户可以修改后重新提交，最多两次。

## 身份核验会妨碍报价吗？

您可以随时起草报价，但必须在每个必填身份项目都通过之后才能发送。上传文件并不等于通过，是否通过由您决定。

## 各状态是什么意思？

| 状态 | 含义 |
| --- | --- |
| 待审核 | 等待您作出决定 |
| 客户修改中 | 您已把案件退回，客户正在修改 |
| 待报价 | 您已接受，下一步发送报价 |
| 已报价 | 报价在客户手中 |
| 已付款 | 客户已付款，案件工作台已开放 |
| 已拒绝 | 您已拒绝，客户可以重新提交 |
| 已取消 | 案件已取消 |

<Warning>
Orbid 的 AI 可以帮助阅读文件，但绝不会替您通过任何身份项目，由您自己决定。
</Warning>

## 遇到问题怎么办

| 您看到的提示 | 处理方法 |
| --- | --- |
| “其他人已处理过该案件” | 列表已刷新。请先查看新的状态再操作。 |
| “项目未通过时请填写原因” | 填写原因后再次保存。 |
| “该项目尚未上传文件，无法通过” | 用**要求补件**请客户提供文件。 |
| “文件不可用……无法标记为通过” | 请客户重新上传。 |
