文件库（页面标题为“合同知识库”）会保存律所的文件，方便您检索其中的条款并重复使用。您可以上传 DOCX、DOC、PDF、TXT 和 MD 文件，每个最大 50 MB。

## 开始之前

- 确认这些文件可以在本所内部共享。
- Orbid 会去除上传文件中的个人信息，但您仍应自行检查结果。

## 如何上传？

<Steps>
  <Step title="打开文件库">
    在侧边栏选择**文件库**。页面标题是“合同知识库”。
  </Step>
  <Step title="上传">
    选择**上传**，再选择**选择文件**或**选择文件夹**。
  </Step>
  <Step title="选择是否保留原件">
    **保留原件**默认开启。只有您本人和管理员可以打开原件。
  </Step>
  <Step title="等待状态变为“就绪”">
    Orbid 会读取每个文件并拆分为条款。只有“就绪”的文件才能被检索。
  </Step>
</Steps>

| 项目 | 限制 |
| --- | --- |
| 文件类型 | DOCX、DOC、PDF、TXT、MD |
| 单个文件大小 | 50 MB |

不支持的类型或过大的文件会被跳过。如果文件已在知识库中，Orbid 会提示“库中已有”。

## 各状态是什么意思？

| 状态 | 含义 |
| --- | --- |
| 排队中 | 正在等待处理 |
| 解析中 | Orbid 正在读取文件 |
| 脱敏中 | 正在去除个人信息 |
| 归类中 | Orbid 正在判断文件类型 |
| 待复核 | 需要人工检查 |
| 就绪 | 可以检索其中的条款 |
| 失败 | 处理未成功 |

## 如何检索？

选择**检索条款**，描述您需要的条款即可，可以使用任何语言。您也可以选择条款类型。没有搜到结果，并不表示一定没有相关内容。

## 可以把已交付的文件存入知识库吗？

可以。在已交付的文件上选择**存入合同库**。只有已交付的合同可以存入，案件本身不会改变。一次最多可以存入 20 个文件。

## 文件保存多久？

只有律所管理员可以更改文件的保存期限。

- 可选择保存 1、2、3、5、7 或 10 年，或选择**永久**。
- 期限从文件上传当天算起，或从最近一次用于起草的日期算起。
- 保存前，预览会显示将删除多少份文件。
- 删除会在夜间进行，删除后无法恢复。
- 已授权的文件不受影响。

## 遇到问题怎么办

| 您看到的提示 | 处理方法 |
| --- | --- |
| 状态为“失败” | 重新上传该文件，或换一份副本。 |
| 状态为“待复核” | 打开文件并完成复核。 |
| “已跳过（类型不支持或超过 50 MB）” | 转换文件格式或压缩文件。 |
| 无法下载原件 | 只有上传者和管理员可以下载，请联系他们。 |
