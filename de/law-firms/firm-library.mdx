Die Dateibibliothek (Seitentitel: Vertragsbibliothek) bewahrt die Dokumente Ihrer Kanzlei auf, damit Sie ihre Klauseln durchsuchen und wiederverwenden können. Sie können DOCX-, DOC-, PDF-, TXT- und MD-Dateien bis 50 MB hochladen.

## Bevor Sie beginnen

- Dokumente, die Sie innerhalb Ihrer Kanzlei teilen dürfen.
- Orbid entfernt persönliche Angaben aus Uploads. Prüfen Sie das Ergebnis trotzdem.

## Wie lade ich hoch?

<Steps>
  <Step title="Bibliothek öffnen">
    Wählen Sie in der Seitenleiste **Dateibibliothek**. Der Seitentitel lautet Vertragsbibliothek.
  </Step>
  <Step title="Hochladen">
    Wählen Sie **Hochladen** und dann **Dateien wählen** oder **Ordner wählen**.
  </Step>
  <Step title="Entscheiden, ob das Original bleibt">
    **Originaldatei behalten** ist standardmäßig eingeschaltet. Nur Sie und Administratoren können das Original öffnen.
  </Step>
  <Step title="Warten, bis „Bereit“ erscheint">
    Orbid liest jede Datei und teilt sie in Klauseln auf. Nur Dokumente mit dem Status „Bereit“ lassen sich durchsuchen.
  </Step>
</Steps>

| Punkt | Grenze |
| --- | --- |
| Dateitypen | DOCX, DOC, PDF, TXT, MD |
| Größe einer Datei | 50 MB |

Nicht unterstützte oder zu große Dateien werden übersprungen. Ist eine Datei schon in der Bibliothek, meldet Orbid „Bereits in der Bibliothek“.

## Was bedeuten die Statusangaben?

| Status | Bedeutung |
| --- | --- |
| In Warteschlange | Wartet, bis sie an der Reihe ist |
| Wird gelesen | Orbid liest die Datei |
| Wird anonymisiert | Persönliche Angaben werden entfernt |
| Wird klassifiziert | Orbid ermittelt die Dokumentart |
| Zu prüfen | Eine Person muss es prüfen |
| Bereit | Sie können die Klauseln durchsuchen |
| Fehlgeschlagen | Es hat nicht geklappt |

## Wie suche ich?

Wählen Sie **Klauseln suchen**. Beschreiben Sie die gewünschte Klausel, in jeder Sprache. Sie können auch eine Klauselart wählen. Kein Ergebnis beweist nicht, dass es nichts Passendes gibt.

## Kann ich eine übergebene Datei in der Bibliothek speichern?

Ja. Wählen Sie bei einer übergebenen Datei **In Vertragsbibliothek speichern**. Nur übergebene Verträge lassen sich speichern. Das Mandat bleibt unverändert. Sie können bis zu 20 Dateien gleichzeitig speichern.

## Wie lange bleiben Dateien erhalten?

Nur Administratoren der Kanzlei können ändern, wie lange Dokumente aufbewahrt werden.

- Wählen Sie, Dokumente 1, 2, 3, 5, 7 oder 10 Jahre zu behalten, oder **Unbegrenzt**.
- Die Zeit zählt ab dem Tag des Hochladens oder ab der letzten Verwendung beim Entwerfen.
- Vor dem Speichern zeigt eine Vorschau, wie viele Dokumente gelöscht werden.
- Das Löschen läuft über Nacht. Gelöschte Dokumente lassen sich nicht zurückholen.
- Lizenzierte Dokumente sind nicht betroffen.

## Wenn etwas nicht klappt

| Was Sie sehen | Was zu tun ist |
| --- | --- |
| Status „Fehlgeschlagen“ | Laden Sie die Datei erneut hoch oder versuchen Sie eine andere Kopie. |
| Status „Zu prüfen“ | Öffnen Sie sie und schließen Sie die Prüfung ab. |
| „Übersprungen (nicht unterstützter Typ oder über 50 MB)“ | Wandeln Sie die Datei um oder verkleinern Sie sie. |
| Sie können das Original nicht herunterladen | Nur wer es hochgeladen hat und Administratoren können das. Fragen Sie eine dieser Personen. |
