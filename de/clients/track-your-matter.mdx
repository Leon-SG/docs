Ihr Arbeitsbereich zeigt jedes Mandat, seinen Fortschritt, Ihre Nachrichten und alles, was die Kanzlei von Ihnen braucht. Öffnen Sie ein Mandat, um Ihren nächsten Schritt zu sehen.

## Wie lese ich den Fortschrittsbalken?

| Stufe | Bedeutung |
| --- | --- |
| Erfassung | Sie beschreiben das Mandat noch. |
| KYC | Sie laden Ausweisunterlagen hoch. |
| Anwaltsprüfung | Der Anwalt liest Ihr Mandat. |
| Angebot | Die Kanzlei hat zugesagt und sendet oder hat einen Preis gesendet. |
| Zahlung | Ein Angebot wartet darauf, dass Sie bestätigen und bezahlen. |
| In Bearbeitung | Sie haben bezahlt und der Anwalt arbeitet. |
| Geliefert | Ihre Dokumente sind bereit. |

Ihre Startseite sortiert die Mandate in drei Gruppen: **Wartet auf dich**, **In Bearbeitung** und **Geliefert**. Mandate, die Sie betreffen, erscheinen zuerst.

Jedes Mandat trägt außerdem ein kleines Etikett, das sagt, was gerade passiert.

| Etikett | Bedeutung |
| --- | --- |
| Wird beschrieben | Sie schreiben Ihre Antworten noch. |
| Umfang offen | Prüfen und bestätigen Sie, was die Arbeit umfasst. |
| Wartet auf dich | Ein Schritt wartet auf Sie. |
| Wartet auf eine Anwältin oder einen Anwalt | Die Kanzlei organisiert einen Anwalt. Von Ihnen ist nichts nötig. |
| Anwaltsprüfung | Der Anwalt liest Ihr Mandat. |
| Übergabe zu bestätigen | Ihre Dokumente sind da. Bestätigen Sie den Erhalt. |
| Geliefert | Das Mandat ist abgeschlossen. |

## Wie schreibe ich der Kanzlei?

<Steps>
  <Step title="Mandat öffnen">
    Wählen Sie das Mandat in Ihrer Liste.
  </Step>
  <Step title="Empfänger wählen">
    Wählen Sie unter „An“ XiaoOu (den KI-Assistenten von Orbid) oder Ihren Anwalt. Eine Nachricht bedeutet nicht, dass die Kanzlei Ihr Mandat angenommen hat.
  </Step>
  <Step title="Schreiben und senden">
    Tippen Sie Ihre Nachricht und senden Sie sie ab.
  </Step>
</Steps>

<Note>
Die KI von Orbid ist ein Hilfsmittel. Fragen Sie Ihren Anwalt, wenn Sie bei etwas unsicher sind.
</Note>

## Was, wenn die Kanzlei weitere Dokumente verlangt?

Der Anwalt kann Sie bitten, einige Ausweisunterlagen erneut hochzuladen. Diese Punkte stehen dann wieder auf „hochzuladen“. Laden Sie dafür neue Dateien hoch. Ihre alten Dateien bleiben gespeichert, gelten aber nicht als bestanden.

## Wenn etwas nicht klappt

| Was Sie sehen | Was zu tun ist |
| --- | --- |
| Sie sehen ein Mandat nicht | Melden Sie sich mit dem Konto des Unternehmens an, dem das Mandat gehört. Ihr Unternehmen kann ein Mandat auf bestimmte Personen beschränken. Fragen Sie Ihre Verwaltung. |
| Ein Mandat zeigt „Wartet auf eine Anwältin oder einen Anwalt“ | Warten Sie. Die Kanzlei organisiert einen Anwalt. Von Ihnen ist nichts nötig. |
| Das Mandat wurde abgelehnt | Siehe [Abgelehntes Mandat erneut einreichen](/de/clients/resubmit-a-declined-matter). |
