Open **Engagement review** to see new matters waiting for your decision. Check each matter and its identity documents. Then accept or decline.

## Before you start

- You need a lawyer account at your firm.

<Steps>
  <Step title="Open the matter">
    Select a matter in the list. Read the summary and the identity checklist.
  </Step>
  <Step title="Check each identity item">
    Open each required item and look at the files. Choose **Pass** or **Fail**, then select **Save result**. A fail needs a reason. The client does not see that reason. To ask for more, select **Request documents**.
  </Step>
  {/* screenshot: counsel-kyc-check | Engagement review with the identity checklist: one item set to Pass, one to Fail with a reason typed in, and the "Save result" button; demo client "Demo GmbH" | role=lawyer | url=/orbid/counsel/engagements */}
  <Step title="Accept or decline">
    Select **Accept matter** to go on to a quote. To say no, select **Decline matter**, write a reason for the client and select **Confirm decline**.
  </Step>
</Steps>

## How do I decline?

Write a reason of at least 10 characters. The client sees it. You can also add an internal note. Only lawyers see that note. A declined client can edit and resubmit up to two times.

## Do identity checks block the quote?

You can draft a quote at any time. You can send it only after every required identity item has passed. Uploading a file does not pass an item. You decide.

## What do the statuses mean?

| Status | Meaning |
| --- | --- |
| Pending review | Waiting for your decision |
| Client editing | You sent the matter back and the client is fixing it |
| To quote | You accepted. Send a quote next. |
| Quoted | The quote is with the client |
| Paid | The client paid. The matter workbench is open. |
| Declined | You said no. The client may resubmit. |
| Cancelled | The matter was cancelled. |

<Warning>
Orbid's AI can help read documents. It never passes an identity item for you. You decide.
</Warning>

## If something goes wrong

| What you see | What to do |
| --- | --- |
| “Someone else already handled this matter” | The list refreshed. Check the new status before you act. |
| “Add a reason when an item fails” | Type the reason, then save again. |
| “Nothing uploaded for this item yet, so it cannot pass” | Ask the client for the file with **Request documents**. |
| “The file is unavailable ... and cannot be marked as passed” | Ask the client to upload it again. |
