# Quickstart

Create an **Agents** session, upload a tender package, and **tell Orbid the outcome you want** in one or two sentences. Review what it returns. You still decide go/no-go and what gets submitted.

Pricing: [orbid.dev/pricing](https://orbid.dev/pricing).

## Before you start

- Access to Orbid AI ([orbid.dev](https://orbid.dev))  
- A tender package (multi-sheet Excel is common; PDF packs also appear)  
- Optional: product datasheets in [Library](/guides/workspace/library) so match quality is higher  

## Your first win (one task)

### 1. Open Agents and start a session

Each session is a workspace for one bid effort: files, conversation, match state, and drafts.

### 2. Give Orbid the tender

Upload the buyer’s package into the session (or attach from Library).

### 3. Delegate in plain language

Paste something like:

```text
Analyze this tender package. Summarize the key technical requirements
and deadlines, then tell me what you need from me next.
```

中文示例：

```text
分析这份标书，总结关键技术要求和截止时间，并告诉我下一步需要我提供什么。
```

Orbid should **scan** the package and answer from the documents—not invent buyer rules.

### 4. Lock one product and match

When you know the model (or after browsing the catalog):

```text
Match our <MODEL> to this tender. Show gaps and deviations I should review.
```

```text
用我们的 <型号> 对这份标书做匹配，列出需要我审的偏差和缺口。
```

Use your real model name. Formal match expects **one** locked product—see [Match workflow](/guides/workflows/match-and-review-gaps).

### 5. Review, then ask for the next artifact

Examples:

```text
Should we bid on this? Give a go/no-go style assessment with red lines.
```

```text
Fill the buyer Excel form from the match. Flag anything you could not evidence.
```

```text
Generate a compliance matrix and a deviation letter draft.
```

### 6. You finish the job

- Check hard limits, evidence, commercial lines  
- Fix catalog facts if the agent was wrong  
- Export, sign, and **submit through the buyer’s channel**  

Orbid does not submit the bid for you.

## If something fails

- **Weak or empty match** — Enrich Library specs; confirm product category; re-match one model
- **Many blank cells after fill** — [Residuals](/concepts/residual)—empty beats invented
- **Unclear if you should bid** — [Go/no-go workflow](/guides/workflows/decide-go-no-go); human still decides
- **Wrong tool / wrong step** — Rephrase as **outcome** (“generate deviation letter”), not internal ids
