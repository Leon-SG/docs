   Wizard steps (progress bar): Choose service · Describe needs · Review details · Verify identity · View progress
   (zh-Hant 選擇業務·說明需求·核對資料·驗證身分·查看進度; de Leistung wählen·Anliegen schildern·Angaben prüfen·Identität prüfen·Fortschritt ansehen; zh 选择业务·说明需求·核对资料·验证身份·查看进度).

   If pop-ups are blocked: "Could not open a new tab. Please allow pop-ups for this site and retry." → troubleshooting row.
2. Lawyer matter workbench tabs: Files · Chat · Agent · Review · KYC (if applicable) · Facts · Asks (only when open requests) · Deliveries
   (zh-Hant 文件·對話·助理·審閱·KYC·事實·補件·交付; de Dateien·Chat·Assistent·Prüfung·KYC·Fakten·Anfragen·Lieferung).
   Do NOT document Facts Edit/Save or revision history (not found).
   Delivery: **Deliver** opens "Confirm delivery": fields "Your name", checkbox "I am authorised to release this draft to the client", buttons Deliver / Cancel.
   If unresolved high-risk findings: warning "There are {n} unresolved high-risk findings…" — you can go back to Review or continue.
   Comments: handled in the export menu — "Keep comments (n)" / "Remove all comments"; versions "Lawyer version (internal + both)" / "Client version (client + both)". Describe simply; no signing-lawyer field.
   "Request documents" lives in Engagement review.
