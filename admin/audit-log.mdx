The **Audit log** shows who changed what in your organization. Administrators can filter it and export up to 5,000 rows to CSV.

## Before you start

- You must be an administrator.

<Steps>
  <Step title="Open the Audit log">
    In your settings, select **Audit log**.
  </Step>
  <Step title="Filter">
    Use **Event**, **From** and **To**. Select **Load more** to see older rows.
  </Step>
  {/* screenshot: settings-audit-log | Audit log filtered to "Member invited" for the last 30 days, with several rows and the "Export CSV" button; demo firm "Muster Rechtsanwälte" | role=admin | url=/orbid/settings/audit */}
  <Step title="Export">
    Select **Export CSV**.
  </Step>
</Steps>

| Limit | Value |
| --- | --- |
| Rows per CSV file | 5,000 |

It records events such as members invited, removed or changed, settings changes, matter access, payments, deliveries and downloads.

## If something goes wrong

| What you see | What to do |
| --- | --- |
| “The start date is after the end date” | Fix the dates. |
| You need more than 5,000 rows | Narrow the dates and export in parts. |
| “Only an admin can see this” | Ask an administrator. |
