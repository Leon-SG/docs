# Knowledge, history & intel

> **Tools reference.** Prefer [Workflows](/guides/workflows) and [What to say](/guides/what-to-say) for daily use.

These skills query organizational knowledge and history, and record outcomes or intel for later bids.

## Skills in this group

- **`query_knowledge` / `propose_knowledge`**
  - User-facing name: Knowledge base
  - Summary: Query / propose org knowledge
- **`search_bid_history` / `query_win_loss` / `record_bid_outcome`**
  - User-facing name: Bid history & outcomes
  - Summary: Learn from past bids
- **`record_competitor_intel` / `query_competitor_baseline` / `record_market_intel`**
  - User-facing name: Competitor / market intel
  - Summary: Capture and query intel
- **`ask_human`**
  - User-facing name: Ask human
  - Summary: Human-in-the-loop prompts
- **`suggest`**
  - User-facing name: Suggestions
  - Summary: In-session suggestions

## When to use

Use these skills inside an [Agents](/guides/workspace/agents-sessions) session at the appropriate phase (see [Core loop](/guides/core-loop)).

## How to use (example utterances)

- `knowledge base` / `any lessons in knowledge base`  
- `record bid outcome`  
- `query win loss`  


## Prerequisites

Available across phases; strongest after real bid work exists.

## Professional notes

- Meta skill `resolve_skill` is internal routing—omit from user workflows.  
- Knowledge never overrides tender hard limits.
