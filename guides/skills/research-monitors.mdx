# Research, opportunities & monitors

> **Tools reference.** Prefer [Workflows](/guides/workflows) and [What to say](/guides/what-to-say) for daily use.

Research and monitor skills help discover opportunities, run structured web research, and set standing monitors. Some monitor tooling may be evolving—validate in your workspace.

## Skills in this group

- **`web_research`**
  - User-facing name: Market / web research
  - Summary: External research on market, regs, competitors
- **`search_opportunities`**
  - User-facing name: Search tender opportunities
  - Summary: Opportunity search
- **`analyze_opportunity`**
  - User-facing name: Analyze opportunity
  - Summary: Opportunity-level analysis
- **`create_monitor` / `list_monitors` / `update_monitor` / `stop_monitor`**
  - User-facing name: Tender monitors
  - Summary: Standing monitors (**capability may be evolving**)
- **`bid_intelligence`**
  - User-facing name: Bid intelligence
  - Summary: Intelligence over bid context
- **`analyze_bid_strategy`**
  - User-facing name: Strategy analysis
  - Summary: Also listed under risk/strategy

## When to use

Use these skills inside an [Agents](/guides/workspace/agents-sessions) session at the appropriate phase (see [Core loop](/guides/core-loop)).

## How to use (example utterances)

- `market research` / `research competitor landscape`  
- `search tenders` / `search opportunities`  
- `create monitor` / `list monitors`  


## Prerequisites

Works on empty sessions for research/opportunity discovery.

## Professional notes

- Do not invent source counts or coverage KPIs; see orbid.dev for marketing claims.  
- Monitors: if behavior is limited in your tenant, treat as evolving.  
- Research exports may use `produce_artifact`.
