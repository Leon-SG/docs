# Agents and sessions

**Agents** is where you work with Orbid. A **session** holds one bid effort—conversation, files, match state, and drafts.

## How to use

1. Create or open a session.  
2. Upload or attach Library files.  
3. Delegate outcomes in plain language ([What to say](/guides/what-to-say)).  
4. Review results; correct or lock product; ask for the next outcome.  
5. Export drafts; you submit outside Orbid.  

## Example

```text
Analyze this tender, then match our <MODEL> and list hard-limit gaps.
```
