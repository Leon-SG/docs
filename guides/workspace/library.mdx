# Library

**Library** is the agent’s file store—datasheets, certificates, reusable packs. Better Library data → better match and fewer residuals.

## How to use

1. Upload product documentation and supporting files.  
2. Let parse/index complete so specs are available.  
3. Attach into a session when starting bid work.
