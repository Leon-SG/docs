# Knowledge

**Knowledge** is organizational context Orbid can query (lessons, certification notes). It never overrides tender hard limits or missing product evidence.

## What to say

```text
Any lessons in knowledge base for similar tenders?
```

```text
知识库里有没有类似经验？
```
