# Product lock & branches

**Product lock** commits a session branch to one model for formal match and fill. **Branches** let teams evaluate alternatives without mixing evidence.

## Everyday

Pick a model → match → if red/yellow, “switch product” and rematch on a clean decision path.

## Professional notes

- One formal match run should not silently blend two models’ specs.  
- Record which branch produced which deliverable package.
