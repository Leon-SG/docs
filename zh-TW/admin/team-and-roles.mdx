管理員一次最多可以邀請 50 人。請選擇角色、寄出邀請，再查看結果。

## 開始前請準備

- 您必須是管理員。
- 準備好電子郵件地址，每行一個，或用逗號分隔。

<Steps>
  <Step title="開啟人員頁面">
    在設定中，開啟 **團隊與成員**（事務所）或 **成員**（客戶公司）。
  </Step>
  <Step title="加入地址">
    在 **批次邀請（Invite several people）** 下，輸入最多 50 個電子郵件地址。在「身分」旁選擇 **成員** 或 **管理員**。
  </Step>
  {/* screenshot: settings-team-invite | 「團隊與成員」頁面，「批次邀請」方塊內有三個地址，以及「傳送邀請」按鈕；示範事務所「Muster Rechtsanwälte」 | role=admin | url=/orbid/settings/team */}
  <Step title="傳送並查看結果">
    選擇 **傳送邀請**。Orbid 會顯示成功與失敗的數量。失敗的地址會留在方塊內，方便您修正。
  </Step>
</Steps>

| 限制 | 數值 |
| --- | --- |
| 每次邀請的地址數 | 50 |

## 有哪些角色？

管理員、合夥人、律師、律師助理、財務、核准人、申請人與檢視者。管理員身分用「成員／管理員」切換來設定。您能選哪些角色，取決於您的帳號。邀請寄出，不代表對方已經加入。

## 遇到問題時

| 您看到的訊息 | 該怎麼做 |
| --- | --- |
| 「不是有效的電子郵件」 | 修正地址。 |
| 「已是成員」或「已邀請」 | 不需要處理。 |
| 「席次已滿」 | 請聯絡您的 Orbid 窗口增加席次。 |
| 「無法傳送」或「請稍後再試」 | 幾分鐘後再試一次。 |
| 「一次最多 50 位」 | 其餘的分成第二批傳送。 |
| 「只有管理員可以查看」 | 請詢問管理員。 |
