以下是您在 Orbid 會看到的用語。

| 用語 | 意思 |
| --- | --- |
| 案件 | 一件法律工作，包含事實、檔案與訊息。 |
| 填寫 | 最前面的步驟，客戶說明案件並上傳身分證明文件。 |
| 委任 | 客戶與事務所之間的約定：審核、接受、報價與付款。 |
| 委任審核 | 事務所的新案件清單，等待決定接受或婉拒。 |
| 報價 | 事務所的固定價格，包含項目、幣別與截止日期。 |
| KYC | 「認識你的客戶」。律師開始工作前進行的身分審查。 |
| 您編輯的版本 | 文件的個人副本，您在這裡修改。原件維持不變。 |
| 案件工作台 | 律師處理已付款案件的工作區，分頁有文件、對話、助理、審閱、KYC、事實、補件與交付。 |
| 交付 | 律師選擇 **交付** 並確認，讓客戶收到完成檔案的步驟。 |
| 文件庫 | 事務所可搜尋的文件與條款資料庫。頁面標題為「合約知識庫」。 |
| 小鷗 | Orbid 給客戶的 AI 助理。最後仍由律師決定。 |
| 提交並鎖定 | 客戶送出案件時的最後一個按鈕。按下後，答案就會鎖定。 |
