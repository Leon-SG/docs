事務所接受您的案件後，會寄來一個固定價格。請確認內容，再選擇 **確認並付款（Confirm & pay）**。您付款後，律師才會開始處理。

## 開始前請準備

- 等到您的案件出現報價，畫面會顯示「律師已訂出固定價格，確認並付款後即開始處理」。
- 如果貴公司限制誰可以付款，請確認您的帳號有權限。否則請詢問公司的管理員。核准人或財務成員可以付款。

## 該確認哪些內容？

報價卡會顯示詳細內容。

| 項目 | 要看什麼 |
| --- | --- |
| 固定價格 | 您要支付的總額 |
| 幣別 | EUR、USD 或 CNY |
| 有效截止 | 最後一天。卡片上也會寫還剩幾天，例如「剩 5 天」。通常是 14 天，事務所可設定 1 到 60 天。 |
| 版本 | 新的報價會取代舊的報價。 |

如果日期已過，卡片會顯示「已過期」。請見下方「遇到問題時」。

## 狀態標籤是什麼意思？

您的案件會顯示下列其中一個標籤。

| 標籤 | 代表什麼 |
| --- | --- |
| 尚未開始 | 您還沒有送出案件。 |
| 等待審核 | 已送出，我們正在安排律師審核。 |
| 已接受 | 事務所已接受您的案件，接著會寄來報價。 |
| 未接受 | 事務所婉拒了。您可以編輯後重新送出。 |
| 已報價 | 律師已訂出固定價格，確認並付款後即開始處理。 |
| 已付款 | 已付款，律師已開始處理。 |
| 退回修改 | 事務所把案件退回給您。請修改後再送出。 |
| 已取消 | 案件已取消，不會再有後續動作。 |

## 如何付款？

<Steps>
  <Step title="開啟案件">
    選擇有報價的案件。
  </Step>
  <Step title="確認報價">
    確定這是最新的報價，而且還沒過期。
  </Step>
  <Step title="付款">
    選擇 **確認並付款（Confirm & pay）**，再依您的付款方式完成步驟。
  </Step>
</Steps>

價格是固定的。您無法在 Orbid 內議價或拒絕。如果想調整條件，請直接聯絡事務所，事務所可以寄新的報價。

## 遇到問題時

| 您看到的訊息 | 該怎麼做 |
| --- | --- |
| 「此報價已過期，律師會寄新的報價給您」 | 請等候新的報價，或詢問事務所。 |
| 「報價剛剛已更新」 | 先看新的報價，再試一次。 |
| 「線上付款尚未開放」 | 請聯絡事務所，另外安排付款。 |
| 付款失敗 | 先查看報價與付款狀態，再試一次。如果不確定，請先問事務所，以免重複付款。 |
| 已付款但畫面沒變 | 請不要再付一次，直接聯絡事務所。 |
| 「您的角色無法執行此操作」 | 請公司管理員代為付款，或調整您的角色。 |
