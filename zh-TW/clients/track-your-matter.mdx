您的工作區會顯示每件案件、進度、您的訊息，以及事務所需要您做的事。開啟案件，就能看到下一步。

## 進度列怎麼看？

| 階段 | 代表什麼 |
| --- | --- |
| 填寫 | 您還在說明案件。 |
| KYC | 您正在上傳身分證明文件。 |
| 律師審核 | 律師正在閱讀您的案件。 |
| 報價 | 事務所已接受，正在或已經寄出價格。 |
| 付款 | 有一份報價等您確認並付款。 |
| 辦理中 | 您已付款，律師正在處理。 |
| 已交付 | 您的文件已經備妥。 |

首頁會把案件分成三組：**待處理事項**、**進行中**和**已交付**。需要您處理的案件會排在最前面。

每件案件旁還有一個小標籤，說明目前的情況。

| 標籤 | 代表什麼 |
| --- | --- |
| 填寫中 | 您還在撰寫答案。 |
| 需確認範圍 | 請檢查並確認工作內容的範圍。 |
| 等您處理 | 有一個步驟在等您。 |
| 等待律師 | 事務所正在安排律師，您不需要做任何事。 |
| 律師審核中 | 律師正在閱讀您的案件。 |
| 待確認交付 | 文件已送到，請確認您已收到。 |
| 已交付 | 案件已完成。 |

## 如何傳訊息給事務所？

<Steps>
  <Step title="開啟案件">
    在清單中選擇該案件。
  </Step>
  <Step title="選擇收件對象">
    在「收件人」下，選擇小鷗（Orbid 的 AI 助理）或您的律師。傳訊息不代表事務所已接受您的案件。
  </Step>
  <Step title="撰寫並傳送">
    輸入訊息後傳送。
  </Step>
</Steps>

<Note>
Orbid 的 AI 只是輔助工具。如果有任何不確定，請詢問您的律師。
</Note>

## 事務所要求補充文件時怎麼辦？

律師可以要求您重新上傳部分身分證明文件。這些項目會回到「待上傳」，請為它們上傳新檔案。舊檔案會留下紀錄，但不會算作通過。

## 遇到問題時

| 您看到的訊息 | 該怎麼做 |
| --- | --- |
| 看不到某件案件 | 請用擁有該案件的公司帳號登入。貴公司可能把案件限制給特定人員，請詢問管理員。 |
| 案件顯示「等待律師」 | 請稍候，事務所正在安排律師，您不需要做任何事。 |
| 案件被婉拒 | 請見[重新送出被婉拒的案件](/zh-TW/clients/resubmit-a-declined-matter)。 |
