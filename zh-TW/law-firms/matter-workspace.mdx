案件工作台集中了一件已付款案件的對話、事實、檔案與文件。客戶付款後，您就能開啟它。

## 開始前請準備

- 客戶已經支付報價。在那之前，案件會停留在委任審核。

<Steps>
  <Step title="開啟案件">
    在委任審核中，選擇一件已付款的案件，再選擇 **開啟案件工作台（Open matter workbench）**。
  </Step>
  <Step title="閱讀事實、檔案與訊息">
    在請 AI 分析或撰寫任何內容之前，請先閱讀這些資料。
  </Step>
  <Step title="開啟文件">
    確認目前開啟的是哪個檔案。可能是原件、您編輯的版本，或 AI 寫的草稿。
  </Step>
  <Step title="審閱並決定">
    保留您同意的修改。接著前往[交付文件](/zh-TW/law-firms/deliver-documents)。
  </Step>
</Steps>

## 各個分頁有什麼？

工作台有下列分頁。**KYC** 只在案件需要身分審查時才會出現，**補件** 只在您對客戶有未結的要求時才會出現。

| 分頁 | 您在這裡做什麼 |
| --- | --- |
| 文件 | 查看客戶的檔案，並開啟文件。 |
| 對話 | 與客戶讀寫訊息。 |
| 助理 | 請 Orbid 的 AI 分析或撰寫。 |
| 審閱 | 閱讀發現，決定要保留哪些。 |
| KYC | 檢查客戶的身分證明文件。 |
| 事實 | 閱讀蒐集到的案件事實。 |
| 補件 | 追蹤您向客戶要求的文件。 |
| 交付 | 把完成的檔案交付給客戶。 |

## 「您編輯的版本」是什麼？

原件是客戶給您的檔案。您編輯的版本是您自己的副本，您可以在上面修改。AI 寫的草稿則是第三種。儲存或交付之前，請確認您編輯的是哪一個。

## 如何請客戶補充身分證明文件？

請客戶上傳您指定的項目。這些項目會回到「待上傳」，先前的檔案會留下紀錄。如果您改變心意，請再檢查這些項目的狀態，因為它們不會自動恢復。

<Warning>
Orbid 的 AI 只是輔助工具。請自行檢查它的發現、草稿與引用來源。您要為交付的內容負責。
</Warning>

請在委任審核中使用 **請求補件**。

## 遇到問題時

| 您看到的訊息 | 該怎麼做 |
| --- | --- |
| 檔案無法載入或預覽 | 請下載原件，稍後再試。 |
| 草稿沒有完成 | 確認您編輯的版本已儲存，再試一次。 |
| 引用來源遺失或有誤 | 請在交付前修正。 |
