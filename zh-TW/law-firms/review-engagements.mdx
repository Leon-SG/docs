開啟 **委任審核（Engagement review）**，就能看到等您決定的新案件。請檢查每件案件與它的身分證明文件，然後接受或婉拒。

## 開始前請準備

- 您需要事務所的律師帳號。

<Steps>
  <Step title="開啟案件">
    在清單中選擇一件案件，閱讀摘要與身分審查清單。
  </Step>
  <Step title="檢查每個身分項目">
    開啟每個必填項目並查看檔案。選擇 **通過** 或 **未通過**，再選擇 **儲存結果（Save result）**。未通過時必須寫明原因，客戶看不到這個原因。如果需要更多資料，請選擇 **要求補件（Request documents）**。
  </Step>
  {/* screenshot: counsel-kyc-check | 委任審核中的身分審查清單：一項設為通過，一項設為未通過並填寫原因，以及「儲存結果」按鈕；示範客戶「Demo GmbH」 | role=lawyer | url=/orbid/counsel/engagements */}
  <Step title="接受或婉拒">
    選擇 **接受案件（Accept matter）**，繼續進行報價。若要婉拒，請選擇 **婉拒案件（Decline matter）**，寫下給客戶的原因，再選擇 **確認婉拒（Confirm decline）**。
  </Step>
</Steps>

## 如何婉拒？

原因至少要寫 10 個字元，客戶看得到。您也可以另外加一則內部備註，只有律師看得到。被婉拒的客戶最多可以修改並重新送出兩次。

## 身分審查會擋住報價嗎？

您隨時可以起草報價，但必須等所有必填的身分項目都通過後才能寄出。上傳檔案不會讓項目通過，由您決定。

## 各種狀態是什麼意思？

| 狀態 | 意思 |
| --- | --- |
| 待審核 | 等您決定 |
| 客戶修改中 | 您把案件退回，客戶正在修改 |
| 待報價 | 您已接受，下一步是傳送報價 |
| 已報價 | 報價在客戶手上 |
| 已完成付款 | 客戶已付款，案件工作台已開啟 |
| 已拒絕 | 您婉拒了，客戶可以重新送出 |
| 已取消 | 案件已取消 |

<Warning>
Orbid 的 AI 可以協助閱讀文件，但絕不會替您讓身分項目通過。由您決定。
</Warning>

## 遇到問題時

| 您看到的訊息 | 該怎麼做 |
| --- | --- |
| 「已有其他人處理過這件案件」 | 清單已更新。請先看新的狀態，再進行操作。 |
| 「項目未通過時請填寫原因」 | 輸入原因後再儲存一次。 |
| 「此項目尚未上傳任何檔案，無法通過」 | 用 **要求補件** 請客戶上傳檔案。 |
| 「檔案無法使用……無法標示為通過」 | 請客戶重新上傳。 |
