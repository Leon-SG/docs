文件庫（頁面標題為「合約知識庫」）會保存事務所的文件，讓您搜尋其中的條款並重複使用。您可以上傳 DOCX、DOC、PDF、TXT 和 MD 檔案，每個最大 50 MB。

## 開始前請準備

- 您有權在事務所內部分享的文件。
- Orbid 會移除上傳文件中的個人資料，但您仍應自行檢查結果。

## 如何上傳？

<Steps>
  <Step title="開啟文件庫">
    在側邊欄選擇 **文件庫**。頁面標題是「合約知識庫」。
  </Step>
  <Step title="上傳">
    選擇 **上傳**，再選擇 **選擇檔案** 或 **選擇資料夾**。
  </Step>
  <Step title="決定是否保留原件">
    **保留原件** 預設為開啟。只有您和管理員可以開啟原件。
  </Step>
  <Step title="等到狀態變成「就緒」">
    Orbid 會讀取每個檔案，並切分成條款。只有「就緒」的文件才能搜尋。
  </Step>
</Steps>

| 項目 | 限制 |
| --- | --- |
| 檔案格式 | DOCX、DOC、PDF、TXT、MD |
| 單一檔案大小 | 50 MB |

不支援或太大的檔案會被略過。如果檔案已在知識庫中，Orbid 會顯示「已在知識庫中」。

## 各種狀態是什麼意思？

| 狀態 | 意思 |
| --- | --- |
| 排隊中 | 正在等待處理 |
| 解析中 | Orbid 正在讀取檔案 |
| 去識別化中 | 正在移除個人資料 |
| 歸類中 | Orbid 正在判斷文件類型 |
| 待審閱 | 需要有人檢查 |
| 就緒 | 可以搜尋其中的條款 |
| 失敗 | 處理沒有成功 |

## 如何搜尋？

選擇 **檢索條款**。用任何語言描述您要的條款，也可以選擇條款類型。找不到結果，不代表一定沒有相關內容。

## 可以把已交付的檔案存進知識庫嗎？

可以。在已交付的檔案上，選擇 **存入合約庫**。只有已交付的合約可以儲存，案件本身不會有任何變動。一次最多可存 20 個檔案。

## 檔案保存多久？

只有事務所管理員可以變更文件的保存期限。

- 可選擇保存 1、2、3、5、7 或 10 年，或選擇 **永久**。
- 期限從文件上傳當天算起，或從最近一次用於撰寫的日期算起。
- 儲存前，預覽會顯示將刪除多少份文件。
- 刪除會在夜間進行，刪除後無法復原。
- 已授權的文件不受影響。

## 遇到問題時

| 您看到的訊息 | 該怎麼做 |
| --- | --- |
| 狀態為「失敗」 | 重新上傳檔案，或改用另一份複本。 |
| 狀態為「待審閱」 | 開啟後完成審閱。 |
| 「已略過（不支援的格式或超過 50 MB）」 | 轉換格式，或把檔案縮小。 |
| 無法下載原件 | 只有上傳者和管理員可以下載，請向他們詢問。 |
