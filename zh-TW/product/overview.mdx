本清單依據原始碼檢查，不代表已完成正式環境驗收。「已實作」表示找到具體程式碼；「佔位」表示該路徑目前顯示不可用畫面。部署可用性仍待確認。[S01]

## 模組

| 模組 | 適用對象與用途 | 佐證狀態 |
| --- | --- | --- |
| [檔案與資料庫](/zh-TW/product/files) | 律師上傳、尋找與審查文件 | 已實作；功能取決於存取權限 |
| [知識與記憶](/zh-TW/product/knowledge) | 律師端知識、記憶、缺口與品質 | 佔位；實作待確認 |
| [客戶委託資料收集與驗證](/zh-TW/product/intake) | 客戶說明案件、核對事實並提交身分資料 | v2 已實作；舊版 v1 並存 |
| [委任、報價與付款](/zh-TW/product/engagements) | 律師決定是否接受委任；客戶審閱報價並付款 | 已實作；付款服務商的可用性待確認 |
| [客戶工作區](/zh-TW/product/client) | 客戶追蹤案件、訊息、檔案與交付成果 | 已實作；適用可見性規則 |
| [律師文件作業](/zh-TW/product/counsel) | 律師管理案件、審閱文件並交付成果 | 已實作；獨立的品質／知識／記憶／缺口頁面為佔位頁面 |
| [設定與存取權限](/zh-TW/product/settings) | 工作區使用者找到帳號與組織控制項 | 路徑已實作；完整角色矩陣與商業方案權益待確認 |

## 規劃中與尚不可用的範圍

介面規格書描述了律師端的知識審查狀態、限定範圍的記憶、具優先順序的缺口及品質看板。但這些獨立路徑目前顯示佔位頁面。應視為規格書中已提出、實作情況尚待確認的意圖，不得據此推定推出日期。交付檢查清單也預留了格式檢查項目，但明確指出目前尚無格式檢查器。[S02, S12]
