設定路徑提供組織、帳號、存取權限與用量設定的入口。路徑存在，不代表每個帳號都可編輯所有設定，也不代表每個連接器都已啟用。[S19]

## 尋找設定

使用目前工作區的設定入口。律師工作區在共用網域的路徑對應使用 `/orbid/settings`，包含以下區段代稱；專屬網域可能使用不同前綴：

| 區段 | 路徑尾段 |
| --- | --- |
| 事務所／公司簡介 | `firm` |
| 連接器 | `connectors` |
| 團隊 | `team` |
| 代理程式政策 | `agent-policy` |
| 訂閱／計費 | `billing` |
| 帳號 | `account` |
| 代理程式偏好設定 | `agent` |
| 語言 | `language` |
| 用量 | `usage` |
| 案件存取權限 | `matter-access` |
| 通知 | `notifications` |
| 稽核 | `audit` |

開啟相關區段、檢查您的角色可用的選項、進行允許的變更，並驗證已儲存。不要假設可以透過直接網址使用隱藏控制項。客戶專屬設定有 `/orbid/client/settings` 下的路徑，但受檢查的頁面在客戶設定功能關閉時會回傳找不到頁面。可用性與可編輯項目取決於設定及權限，也不代表可管理事務所。[S25]

客戶設定的路徑對應包含以下區段：[S25]

| 區段 | 路徑尾段 |
| --- | --- |
| 個人資料 | `profile` |
| 偏好設定 | `preferences` |
| 通知 | `notifications` |
| 安全性 | `security` |
| 公司 | `company` |
| 成員 | `members` |
| 案件存取權限 | `matter-access` |
| 計費 | `billing` |
| 稽核 | `audit` |

## 團隊與邀請

管理員可使用批次邀請功能時，可輸入最多 **50** 個地址、選擇畫面提供的成員或管理員角色，並逐一檢查結果。本次檢查的流程逐項處理邀請，因此同一次操作可能部分成功；地址無效、席次限制或身分服務無法使用都可能造成失敗。表單會保留失敗項目供修正。邀請已送出不代表對方已加入。[S45]

本次檢查的細分成員角色面板在功能開關關閉時會隱藏。面板可用時，只有管理員能變更該組織提供的非管理員角色；此面板不能變更管理員的組織角色。請與管理員確認預期權限及儲存結果，不要僅從角色名稱推論權限。[S47]

在本次檢查的組織成員管理途徑中，若該請求讀到的成員清單顯示對象是最後一位管理員，系統會拒絕移除或降級。這項檢查與身分服務更新是分開的步驟，不能依賴它協調並行變更；請逐一變更管理員並確認結果。若變更角色或移除成員時回報失敗，重試前請重新載入成員清單並確認結果：這些操作包含多個身分服務步驟，可能在途中失敗。若狀態不明，請聯絡管理員。[S51] 待確認事項請見 [Q17](/zh-TW/product/open-questions)。

## 連接器

在本次檢查的事務所連接器設定中，獲授權的編輯者可選擇啟用區域與預設來源。儲存偏好不代表連接器已設定完成或可連線。若沒有有效的預設來源且事務所來源區域已啟用，解析程式會回退至 `knowledge` 預設值；因此取消最後一個預設項目不一定會留下空白選擇。請確認儲存結果與實際來源狀態，不要將核取方塊視為存取控制保證。[S49]

## 通知偏好

若通知設定區段可用，請選擇畫面列出的事件及電子郵件或應用程式內管道，儲存後確認結果。偏好依使用者儲存，事務所與客戶端的設定彼此分開。本次檢查的程式碼將未指定的選項預設為啟用。受檢查的郵件傳送流程只對已對應的事件套用偏好；其他里程碑郵件仍可能寄出，且讀取偏好失敗時會允許寄送。儲存偏好並不保證每則通知一定送達或一定被停用。[S26]

## 存取權限與歸屬

### 稽核紀錄

本次檢查的稽核畫面不是完整活動紀錄：稽核寫入採盡力處理、拒絕存取事件採抽樣記錄，且案件事件紀錄讀取失敗時，結果可能只剩組織事件。CSV 匯出最多 **5000** 列。可使用的話，請搭配篩選與分頁，並向負責系統或管理員核對重要事件；缺少紀錄不能證明操作未發生。[S50]

### 客戶公司身分

在本次檢查的客戶公司設定中，管理員變更法定名稱、登記號碼或管轄地時，伺服器會將變更欄位標記為需要 KYC 複查。儲存公司資料不代表複查已完成。變更法定名稱時也會嘗試同步顯示名稱，但同步可能失敗；請確認顯示結果，若仍不一致，請聯絡管理員或事務所。[S44]

### 案件存取權限

在本次檢查的案件存取設定中，客戶組織管理員可選擇 `all` 或 `members` 可見性。額外的成員限制只有在伺服器強制模式啟用時才會阻擋存取；關閉與觀察模式不會強制執行。依賴此設定前，請確認部署模式。[S25, S43]

事務所設定表單可讓管理員儲存預設案件成員，但介面說明指出，自動加入新案件屬於後續版本。因此，儲存預設值不能證明任何人已加入特定案件；請檢查該案件的實際成員與存取權限。[S43]

客戶組織身分、事務所工作區指派、案件可見性與個別操作限制，是不同事項。委任審查與文件作業可能要求不同狀態。導覽入口不是授權規則。請由管理員處理不一致情況，不要修改無關組織資料以取得存取權限。

完整角色／權限矩陣、邀請生命週期、連接器前提、政策效果、稽核涵蓋範圍與允許的管理變更仍列於 [Q15](/zh-TW/product/open-questions)。

## 計費與下載

本次檢查的客戶計費頁最多讀取公司 **500** 筆案件紀錄。畫面顯示的付款金額與幣別取自該案件最後找到的發票（如有），而非直接取自付款服務商交易；因此付款清單或金額可能不完整，或與實際扣款不同。列出的卡號末四碼是曾使用的方式，不代表卡片保管庫。請與約定報價及服務商紀錄核對；若有差異，請聯絡事務所。[S48] 對帳待確認事項請見 [Q16](/zh-TW/product/open-questions)。

產品方案資訊請見 [orbid.dev/pricing](https://orbid.dev/pricing)。本手冊不從原始碼常數推論價格或額度。客戶委任付款依各自報價進行；確認前請核對操作與金額。

支援的公開 API、訂閱權益、地區主機代管、資料保留與服務保證，需要明確的產品文件。請參閱[共通規則](/zh-TW/product/rules)與[待確認事項](/zh-TW/product/open-questions)。
