# What is the difference between quick rank and formal match?

**Quick rank** is a fast shortlist using coarse signals. **Formal match** evaluates requirements more thoroughly against product specifications and evidence. Rank is for selection; formal match is for compliance confidence before fill.

## Details

- **Goal**
  - Quick rank: Shortlist
  - Formal match: Compliance confidence
- **Depth**
  - Quick rank: Shallow
  - Formal match: Requirement-heavy
- **Use before fill**
  - Quick rank: No (alone)
  - Formal match: Yes

### Anti-pattern

Using rank score as a substitute for hard-limit review. A high soft score can still fail a knockout row.
