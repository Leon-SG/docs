# What is an agent session?

An **Agents session** is where you talk to Orbid AI: upload tender files, lock a product, and run scan → match → fill → deliverables in one conversation thread. Session context (files, match state, downloads) drives the tool loop. Sessions are not a multi-module CRM—they are task workspaces.

## What lives in a session

- Chat prompts and tool runs  
- Uploaded tender packages  
- Match/fill drafts and downloads  

## What stays outside the session

- Buyer portal submission  
- Company SSO and billing setup  
- Legal final approval process  

## Everyday path

1. Open **Agents** and start a session.  
2. Upload the tender package.  
3. Say what you want in plain language (see [What to say](/guides/what-to-say)).  
4. Review outputs; continue in the same session for fill/deliverables.
